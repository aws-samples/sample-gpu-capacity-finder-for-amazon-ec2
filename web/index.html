      Manage users

      This page signs people in with Amazon Cognito. The page does not create or change users: you do that in the AWS Management Console. Only people with the right AWS permissions can open the user pool there. If you cannot, ask your administrator.

      Open Amazon Cognito console (opens in a new tab)

      Add a user

      1. Choose Create user.
      2. Choose Send an email invitation.
      3. Enter the person's email address. They sign in to this page with it.
      4. Select Mark email address as verified. Email alerts need a verified address.
      5. For the temporary password, choose Generate a password, then choose Create user.
      6. Cognito emails the person a temporary password that is valid for 7 days. At first sign-in, they set a new password and enroll an authenticator app, because this page requires multi-factor authentication (MFA).

      Update a user

      1. In the Users list, find the person by email address and open their details.
      2. If the temporary password expired before the first sign-in, send the invitation again from their details page.
      3. If they forgot their password, choose Reset password. Cognito emails them a code, and they set a new password at the next sign-in.
      4. If they have a new phone, remove their authenticator app (or reset their MFA) on their details page. At the next sign-in, they enroll the app again.
      5. To stop someone from signing in, choose Disable user access. Their email alerts continue until you remove them.

      Delete a user

      1. In the Users list, find the person by email address and open their details.
      2. If the console asks, choose Disable user access first.
      3. Choose Delete user and confirm.

      Their email alerts and email subscription stay until you remove them. See Remove a user and their leftovers in the administrator guide.

      Reserve with the AWS CLI

      An On-Demand Capacity Reservation holds EC2 capacity for one instance of this type in this Availability Zone, so a later launch there has room. The command reserves one Linux instance and ends the reservation one hour after you run it, unless you cancel it first. To use it, launch the same type in the same zone and target the reservation (the command uses targeted matching). This is an example command: change the instance count, the end date, or other parameters as you need before you run it.

      A Capacity Reservation bills at the On-Demand rate from the moment it is created until it ends or you cancel it. This page does not create it for you.
